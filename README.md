# 🖤 Komeback365

**A year-long habit tracker, daily timetable and progress dashboard — built as a single self-contained website.**

No backend, no sign-up, no build step. Open it, log your day, and watch a GitHub-style contribution grid fill up in real time.

🔗 **Live site:** [k4hav.github.io/komeback](https://k4hav.github.io/komeback/)
👤 **Author:** [@k4hav](https://github.com/k4hav)

---

## ✨ Features

- **365-day contribution grid** — one box per day, colored by how much of that day's goals were hit. Scroll or jump between years, with new years generated on the fly.
- **Daily habit log** — toggle yes/no habits (sleep on time, no social media, clean food) and log amount-based habits (exercise, study, coding, communication practice, screen time) against a goal.
- **Fully custom habits** — add your own (reading, water intake, gym, prayer — anything) as either a yes/no or a measured amount, each with its own daily goal.
- **Editable weekly timetable** — a separate schedule for college days, Saturdays and Sundays, with live "happening now" highlighting.
- **Insights dashboard** — current and best streaks, monthly breakdowns, and a weight-over-time chart.
- **Liquid-glass, dark UI** — smooth motion throughout, and fully respects `prefers-reduced-motion`.
- **Private by default** — all data lives in your browser's `localStorage`. Nothing is sent anywhere.
- **Backup & restore** — export your data as text/JSON any time and restore it on another browser or device.

## 🛠️ Built with

Plain **HTML, CSS and JavaScript** — one file, zero dependencies, zero frameworks. Google Fonts (Bricolage Grotesque + Instrument Sans) are the only external request.

## 🚀 Running it locally

```bash
git clone https://github.com/k4hav/komeback.git
cd komeback
```

Then just open `index.html` in any browser. That's it — no `npm install`, no server required.
